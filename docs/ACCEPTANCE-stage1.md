# Приёмка этапа 1 — чек-лист для владельца

Нужна чистая Windows 11 x64 (виртуалка подойдёт, но лучше живой ПК на домашнем провайдере). Secure Boot и «Целостность памяти» оставить включёнными, как из коробки. Установщик — `TenBoost-Setup.exe` из артефакта последнего зелёного прогона `build` (Actions → build → Artifacts).

## 0. Снимок «до»

В PowerShell от администратора, вывод сохранить в файл `before.txt`:

```
ipconfig /all; route print; netsh winhttp show proxy; sc.exe query windivert; Get-NetAdapter | ft Name,Status
```

Открыть youtube.com, включить любое видео в 1080p, записать: грузится ли, буферизуется ли.

## 1. Установка

- [ ] Засечь время от двойного клика по `TenBoost-Setup.exe` до зелёного значка «T» в трее. **Критерий: меньше 2 минут.**
- [ ] Посчитать клики, включая SmartScreen («Подробнее» → «Выполнить в любом случае») и UAC. Записать.
- [ ] Значок в трее зелёный, подсказка «TenBoost — включено».

Если значок красный — навести на него и записать текст ошибки, приложить `C:\ProgramData\TenBoost\logs\service.log`.

## 2. Драйвер и антивирус

- [ ] `sc.exe query windivert` → `STATE: 4 RUNNING`. Если драйвер не загрузился при включённом Secure Boot — **стоп, это блокер всего проекта**, приложить лог.
- [ ] Через 10 минут после установки файлы на месте: `dir "C:\Program Files\TenBoost\engine"` показывает `winws2.exe` и `WinDivert64.sys`; в «Безопасность Windows → Журнал защиты» нет записей про TenBoost.

## 3. YouTube

- [ ] youtube.com открывается, видео 1080p играет без буферизации.
- [ ] Правый клик по значку → «Выключить» → значок серый; видео снова тормозит как в п. 0. «Включить» → снова зелёный и работает.
- [ ] Перезагрузить ПК: после входа значок сам появился и зелёный.

## 4. Удаление

- [ ] «Параметры → Приложения → TenBoost → Удалить».
- [ ] `sc.exe query TenBoost` → служба не найдена (1060).
- [ ] `sc.exe query windivert` → не найдена (если до установки её тоже не было).
- [ ] Папок `C:\Program Files\TenBoost` и `C:\ProgramData\TenBoost` нет.
- [ ] Повторить команды из п. 0 в `after.txt`, сравнить с `before.txt`: адаптеры, маршруты и прокси те же. Сайты открываются как до установки.

## 5. Конфликт (по возможности)

- [ ] Поставить GoodbyeDPI или zapret из win-bundle как службу, затем TenBoost. Установщик должен показать окно со списком найденных программ. «Да» — они остановлены, TenBoost работает. «Нет» — установка отменена, система не изменилась.

Результаты — в `REPORT-stage1.md`, раздел «Приёмка».
